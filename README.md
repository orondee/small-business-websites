# GreenLine Lawn Care

A responsive, one-page website for a fictional neighborhood lawn-care company. This beginner-friendly portfolio project is built with plain HTML and CSS and runs locally without setup or paid services.

> **Portfolio sample:** GreenLine Lawn Care and its contact details are fictional. The contact form is a visual demo and does not send or store submissions.

## Preview

Open [index.html](index.html) in a browser to view the site locally.

## Features

- Hero section, three service cards, about section, and contact section
- Green-and-white visual style with an original CSS landscape illustration
- Responsive layout for desktop, tablet, and phone screens
- Keyboard focus styles and labeled form fields
- No JavaScript, build tools, dependencies, or paid services

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and `styles.css` in the same folder.
3. Open `index.html` in a web browser.

To edit the page content, change the HTML in `index.html`. To adjust colors, spacing, and layout, edit `styles.css`.

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Page content and semantic structure |
| `styles.css` | Colors, typography, layout, illustration, and responsive rules |

## Contact form

The form is intentionally front-end only. It demonstrates accessible labels and input styling, but it does not deliver messages. The example email and phone number are placeholders.
