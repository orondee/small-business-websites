# Small Business Website Portfolio (React)

Modern, mobile-friendly website concepts for small service businesses, rewritten as a high-performance React + TypeScript application with Vite.

## Overview

This application showcases website design concepts for small businesses:
- **Portfolio Homepage**: Overview of selected client concepts and guiding web design principles.
- **GreenLine Lawn Care**: A confident, approachable lawn-care brand featuring service overviews, perks, about section, and an interactive sample estimate request form with client-side validation.
- **BrightSide Home Cleaning**: A calm, editorial cleaning brand featuring a service menu with checklists, brand philosophy, and concept details.
- **404 Page**: Responsive not-found fallback view.

## Features Preserved

- Responsive mobile navigation with escape-key support and accessible ARIA states.
- Dedicated visual themes per project (typography, palettes, and layouts).
- Interactive sample estimate form with real-time validation and preview generation.
- Scroll-triggered reveal animations with full `prefers-reduced-motion` compliance.
- Client-side routing with URL synchronization and smooth anchor scrolling.
- Skip-to-content links for keyboard accessibility.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Modular CSS preserving original design tokens and layout

## Getting Started

To run the application locally:

```bash
npm install
npm run dev
```

The application runs on `http://0.0.0.0:3000`.
