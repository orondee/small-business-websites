## Overview

This application showcases website design concepts tailored for local service businesses:
- **Portfolio Homepage**: Overview of selected client concepts, guiding studio standards, custom vs template comparison matrix, and an interactive Project Scope & Investment Estimator.
- **GreenLine Lawn Care**: A confident, approachable lawn-care brand featuring an interactive Yard Footprint Visualizer, customized Field Route Work Order Slip, perks checklist, service tiers, and validated estimate inquiry form.
- **BrightSide Home Cleaning**: A serene, editorial residential cleaning brand featuring 3-tier side-by-side package cards, room-by-room steppers, cadence courtesy rates, Care Ledger summary, and consultation booking form.
- **Responsive Viewport Simulator**: Direct in-app preview switching between Full Desktop, 768px Tablet, and 390px Mobile Phone chassis.
- **404 Page**: Responsive not-found fallback view.

## Features & Polish

- **Scroll Progress**: Global reading/scroll progress indicator bar mounted at the top of the viewport.
- **Responsive Mobile Navigation**: Single-thumb friendly touch targets with accessible ARIA states and Escape-key closure.
- **Interactive Estimators**: Bespoke calculation tools for lawn yard sizes and residential room counts with one-click form autofill.
- **Zero-Pill Typography**: Clean unboxed metadata with subtle typographic separators (`·`).
- **Accessible & Fast**: Full `prefers-reduced-motion` support, WCAG AA color contrast, and sub-second load times.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Modular CSS preserving authentic brand tokens and typography (DM Sans, DM Serif Display, Manrope, Plus Jakarta Sans, Instrument Serif)

## Local Development

To run the application locally on your machine:

```bash
npm install
npm run dev
```

The application runs locally on `http://localhost:3000`.

To build for production:

```bash
npm run build
```
